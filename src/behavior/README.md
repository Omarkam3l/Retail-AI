# Behavior Module

This package defines the interfaces, exceptions, and models for the Behavior Analysis Engine, which aggregates primitive events and flags suspicious customer patterns.

## Contents
* `types.py` — Dataclasses for `PrimitiveEvent` and `BehaviorFlag`.
* `interfaces.py` — Declares the `BaseBehaviorEngine` interface.
* `exceptions.py` — Defines `BehaviorEngineError`.
