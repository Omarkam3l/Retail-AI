# Common Module

This package contains shared dataclasses, types, custom exceptions, global system constants, and architectural utilities such as the Dependency Injection container and the logging configuration.

## Contents
* `types.py` — Bounding boxes, poses, detections, frame metadata models.
* `exceptions.py` — Application domain error classes.
* `interfaces.py` — General service interfaces like `Lifecycle`.
* `di.py` — Lightweight Service Container.
* `logging_config.py` — JSON / Console logging wrapper.
* `constants.py` — Global variables and configuration defaults.
