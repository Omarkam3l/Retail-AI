# Success Metrics and KPIs - Retail AI Surveillance Platform

This document defines the metrics and Key Performance Indicators (KPIs) to measure the success, reliability, and accuracy of the Retail AI Surveillance Platform.

---

## 1. Computer Vision & Accuracy Metrics

These metrics evaluate the performance of our deep learning models (YOLO, tracking, action classification) on our test datasets and in real-world retail deployments.

### 1.1 Model Accuracy
* **Recall (Detection Rate)**: The percentage of actual theft/concealment events correctly flagged by the system.
  $$\text{Recall} = \frac{\text{True Positives}}{\text{True Positives} + \text{False Negatives}}$$
  - *Target*: **>= 85%** on our validation datasets; **>= 80%** in real-store environments.
* **Precision**: The percentage of alerts generated by the system that correspond to actual suspicious behavior.
  $$\text{Precision} = \frac{\text{True Positives}}{\text{True Positives} + \text{False Positives}}$$
  - *Target*: **>= 75%** in active operation (ensuring workers do not ignore alerts).
* **False Positive Rate (FPR)**: The frequency of incorrect alerts per camera.
  - *Target*: **< 1.0 false alert per camera per 8-hour shift**.

### 1.2 Multi-Object Tracking Metrics
* **MOTA (Multi-Object Tracking Accuracy)**: Measures tracking errors (misses, false positives, identity switches).
  - *Target*: **MOTA >= 60%** in crowded supermarket store environments.
* **Identity Switches (IDSW)**: The number of times a tracked customer changes ID due to occlusion.
  - *Target*: **< 3 identity switches** per customer path inside the store.

## 2. Engineering & Performance SLA Metrics

These metrics measure the hardware efficiency, system latency, and software reliability of the edge-cloud hybrid platform.

### 2.1 Processing Speed & Throughput
* **Inference FPS (Frames Per Second)**: The number of frames analyzed per camera stream.
  - *Target*: **>= 15 FPS** constant processing rate per camera.
* **Stream Capacity per Edge Node**: The number of 1080p camera feeds managed by a budget-friendly edge box.
  - *Target*: **4 camera streams** on a standard NVIDIA Jetson Orin Nano (8GB) or Intel NUC with OpenVINO.

### 2.2 System Latency
* **Alert Latency**: The time from when the suspect completes the concealment action to when the push notification is received on the store associate's device.
  - *Target*: **<= 5.0 seconds** (p90); **<= 8.0 seconds** (p99).
* **Frame Processing Latency**: The time taken to process a single frame (decode, detect, track, pose).
  - *Target*: **<= 65 milliseconds** per frame.

### 2.3 Edge Resource Constraints
* **GPU Utilization**: The percentage of GPU cores utilized on the edge node.
  - *Target*: **< 85%** average utilization during peak store hours.
* **Memory Usage (VRAM & RAM)**:
  - *Target*: **VRAM < 6GB** (on 8GB edge nodes) and **System RAM < 6GB** (to avoid swapping/crashes).

### 2.4 Cloud SLA
* **API Availability (Uptime)**: The availability of the Cloud Alert Service and S3 media storage.
  - *Target*: **99.9% uptime** (24/7/365).

## 3. Business & Loss Prevention KPIs

These metrics track the financial return on investment (ROI) and behavioral impact on the stores adopting our system.

* **Shrinkage Reduction Rate**: The percentage change in inventory shrinkage after deploying the platform.
  - *Target*: **30% to 50% reduction** in stock shrinkage within 90 days of installation.
* **Alert Response Rate**: The percentage of push alerts reviewed/opened by store associates on their mobile devices.
  - *Target*: **>= 80%** response rate.
* **Average Prevention Time**: The time taken for an associate to check/intervene after receiving an alert.
  - *Target*: **< 60 seconds** average intervention time.
* **Customer Net Promoter Score (NPS)**: Feedback from store owners regarding alert quality and platform usability.
  - *Target*: **NPS >= 45**.
