# Dashboard Guide

## Access
Navigate to `http://localhost:8501` in your browser.

## Pages

### 🏠 Home
Overview with active cameras, total alerts, CPU/memory usage, and pipeline FPS.

### 📷 Live Cameras
View registered cameras, start/stop processing, monitor FPS and frame counts.

### 🚨 Alerts
Browse alerts with severity filtering, pagination, and detailed event information.

### 📊 Event Timeline
Chronological event history with color-coded severity levels.

### 📈 Metrics
Pipeline performance charts including FPS, latency, and per-stage timing.

### 💚 System Health
Real-time CPU, RAM, and GPU usage gauges with system status indicators.

### 🏆 Benchmarks
View evaluation results from the benchmarking framework.

### ⚙️ Settings
Register cameras, configure detection thresholds, and manage alert policies.
